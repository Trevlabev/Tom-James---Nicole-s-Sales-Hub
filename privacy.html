Open deployment guide

Trello authorization

  • The API key may be remembered on the device because it does not grant account access by itself.
  • The Trello user token is session-only and is never included in workspace exports.
  • Disconnect Trello before leaving a shared computer.
  • Use the narrowest authorization duration that works for the office.
  • Revoke the application in Trello account settings if a token may have been exposed.

Security boundary

  • GitHub Pages is a static site and should be treated as publicly accessible.
  • Browser workspace data is not committed to the repository.
  • Exports are downloaded to the device and become the user’s responsibility.
  • External embedded tools must enforce their own authentication and access control.
