Setup & deployment

Publish, configure, and extend the suite.

No build step is required. Commit the files to a GitHub repository and deploy with the included Pages workflow.

GitHub Pages deployment

  1. Create or open the repository.
  2. Upload the contents of this folder to the repository root.
  3. Open Settings → Pages and choose GitHub Actions as the source.
  4. The included workflow deploys the static site.
  5. Open the generated Pages URL and configure links in assets/js/config.js.

Add a new program

  1. Create programs/your-tool/index.html.
  2. Use the shared workspace, utility, shell, and CSS files.
  3. Add the tool to assets/js/programs.js.
  4. Keep secrets and confidential records outside the repository.
  5. For external apps, use a launch link or iframe only when the host permits embedding.

Recommended hosting boundary

GitHub Pages: navigation, training, browser-local utilities, documentation, and safe demos.

Secured host: authentication, shared database, automated Trello/Excel integrations, client records, payroll, banking, or payment data.
